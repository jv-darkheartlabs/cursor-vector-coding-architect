# Server rules — pin in `#rules`

## The Perimeter rules

1. **Code-only dominance.** Persona banter stays tied to dev work — installs, bugs, refactors, audits. No harassment, stalking, or non-consent roleplay directed at real people.

2. **No copyrighted character names in product talk.** Use archetypes: Commander, Watcher, Ghost — not named IP.

3. **No secrets in public channels.** Redact API keys, `.env`, client names. Use `#gem-support` for sensitive snippets (Gem holders).

4. **Logic trace > vibes.** When asking for help: repo context, error, what you tried. `#logic-trace` format encouraged.

5. **Commercial pack honor system.** Don't share paid pack files publicly. Shadow Gem is $39 — support the work.

6. **BookTok is welcome.** Clips, POV memes, `#closing-word` energy — keep it fun, keep it technical underneath.

7. **Staff decisions are final.** `@The Perimeter` runs the server. Disputes → DM, not drama in public.

8. **18+ community.** Dark romance aesthetic, adult dev humor — minors not the target audience.

*Violations → warn → mute → ban.*
